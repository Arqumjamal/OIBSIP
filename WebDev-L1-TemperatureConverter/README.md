# Temperature Converter

A responsive web application for converting temperatures between Celsius, Fahrenheit, and Kelvin.

## Features
- Celsius, Fahrenheit, and Kelvin conversion
- Input validation
- Absolute-zero validation
- Responsive user interface
- Results displayed up to two decimal places

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open index.html in your browser.
2. Enter a temperature.
3. Select the source and target units.
4. Click Convert.
