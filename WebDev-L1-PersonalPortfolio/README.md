
# Personal Portfolio Website

A responsive personal portfolio website showcasing my education, technical skills, projects, and contact information.

## About the Project

This portfolio presents my journey as a Software Engineering student and my interest in frontend development, backend technologies, databases, and artificial intelligence.

## Features

- Responsive design for desktop and mobile devices
- Navigation menu with multiple sections
- About Me section
- Skills and technologies grid
- Project showcase
- Professional contact information
- Mobile navigation menu
- Smooth scrolling
- Back-to-top button

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `WebDev-L1-PersonalPortfolio` folder.
3. Open `index.html` in your web browser.
